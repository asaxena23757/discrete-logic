# discrete-logic
The goal of this project is to build digital logic, transistor by transistor, while using the least amount of integrated circuits as possible.

---
**Project Steps**

The project will be completed in 4 steps: 
- [x] _Create a one bit latch_
  Using two PNPs to create one bit, is able to hold state, but loses it on power down
- [ ] _Astable multivibrator_
  Oscillates instead of holding a state
- [ ] _Gated D latch_
  Adds a data and enable line, transforms into addressable cell
